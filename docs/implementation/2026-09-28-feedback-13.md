## 글꼴 유지

기존 font-family, font-size 선언 변경 없음. 새 HTML 시안의 글자 크기를 게임에 복사하지 않았음.
실제 브라우저 관찰: 운용 제목 23px, 도움말 요약 13px, 상품 범례 12px, 보드 턴 안내 14px.

## 검증

- 전체 테스트: 81개 파일, 790개 테스트 통과.
- 이후 추가한 시장 결과/거래 오류 위치 분리 테스트 포함 design-d2a: 9개 통과. 추가 검사로 총 테스트 수는 791개.
- build, lint, diff whitespace 검사 통과. 기존 500KB 초과 번들 안내 존재(약 553KB).
- 직접/옵션/예약/부분결제/환매 상태에서 상품 합계가 보유액과 일치하며 전체 계좌 합계 유지.
- 조회와 취소가 거래하지 않는 기존 검사 유지. 기존 저장된 판의 운용창·포트폴리오 왕복을 브라우저에서 확인.
- 실제 UI에서 용어 표시, 전체 운용 펼침 위치, 시장 카드 2개와 상품 예시 6개, 범례 7개 확인. 브라우저 오류 로그 없음.
- 관찰한 약 483~498px viewport에서 모달의 clientWidth와 scrollWidth 동일. 보드 턴 안내와 생활 아이콘 사이 약 15.6px 간격.
- 320/390px viewport override를 요청했으나 도구가 반환한 실제 폭은 483/498px였다. 정확한 320/390px 및 실제 iPhone/Windows Edge 실기기 검증으로 주장하지 않음. 이 환경에서는 저장된 3턴 화면의 조회 흐름을 확인했으며, 수동 12턴 완주를 새로 수행하지 않음. 기존 자동 12턴 회귀 검사는 통과.
