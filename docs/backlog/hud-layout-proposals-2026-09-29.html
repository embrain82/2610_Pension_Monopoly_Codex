기념카드 제거 — 확정 방향

작은 탐험 + 기념카드 획득 + 게임/결과 앨범을 함께 제거하고, ‘1장 / 4장 · 기초 다지기’ 같은 장별 목표 안내는 남깁니다.

제거유지
주제 두 곳 선택, 단서와 미니 질문, 기념카드 획득, 내 탐험 앨범장별 목표, 정식 학습 카드·퀴즈, 업적, 보드 발견, 점수·자금·거래

기념카드는 점수·자금 보상이 없는 UI 기록입니다. 기존 저장판의 탐험 기록만 무시하고 금융 상태와 다른 안내 확인 기록은 보존하는 방식으로 제거할 수 있습니다. 기념카드 제거 방향 확정 · 구현 전입니다. 결과 화면의 선택형 이유 남기기도 제거합니다.
