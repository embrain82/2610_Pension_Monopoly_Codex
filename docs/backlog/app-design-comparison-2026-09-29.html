연금로드 × 연결 앱 / DESIGN REVIEW · 2026.09.29

12가지 디자인, 현재와 제안을 한눈에

확정된 보드 하단 A안과 장별 목표 B안의 구조를 유지하면서 색상·정보 위계·카드 표현을 연결 앱에 맞추는 검토안입니다. 본문과 제목 크기는 기존 기준을 유지합니다.

검토용 재구성 화면입니다. 왼쪽은 현재 프로젝트 CSS와 화면 요소를 사용한 대표 예시이며 실제 화면 캡처는 아닙니다. 오른쪽은 같은 정보를 사용한 수정 시안입니다. 금액·금리는 가상 예시이며 실제 계좌 정보는 사용하지 않았습니다. 게임 코드와 저장 데이터는 변경하지 않습니다. 운영 배포 전 로컬 B안도 현재 기준에 포함했습니다.
접이식 메뉴는 직접 눌러볼 수 있어요.
