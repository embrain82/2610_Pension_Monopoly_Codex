흰 배경·녹색 주요 버튼·파스텔 카드·고딕 제목·올리와 원이의 그림을 A-1에서 이어받았습니다. 색을 바꾸는 대신 정보의 우선순위와 배치, 설명의 양, 카드 구조, PC의 분할 방식을 비교합니다.

## 검토 방법

1. 상단에서 화면 단계를 고릅니다. 처음에는 게임판을 보여줍니다.
2. 5개 시안을 눌러 크게 보거나 좌우로 비교합니다.
3. 모바일/PC를 전환하고, 화면 안 버튼·주사위·탭·금액 입력을 눌러봅니다.
4. ♡로 단계별 후보를 하나씩 남깁니다. 선택과 메모를 텍스트로 내보낼 수 있습니다.
5. “03-1 게임판 확정”, “11-3에 11-4 캐릭터 설명 조합”처럼 결정합니다. 후보 저장은 구현 확정과 구분됩니다.

메인은 A-1로 고정하며, 12개 하위 화면은 모두 검토 대기입니다. 검토 순서는 게임판 → 운용 메뉴·주문 → 정산을 권장합니다.

## 프로토타입에 반영한 동작

- 24칸은 현재 보드의 순서·이름을 사용합니다. 주사위 예시는 3+5이며 8칸 이동 후 시장 안내로 연결합니다.
- 성향은 5문항 진단의 화면 흐름을 보여줍니다. 시안에서는 답에 따른 실제 성향을 저장하거나 계산하지 않습니다.
- 디폴트 추천 배지와 선택 체크는 다르게 표시합니다. 지정 안 함도 선택할 수 있습니다.
- 운용 메뉴에서 조회·X 취소는 행동을 소비하지 않습니다. X는 게임 상태를 바꾸지 않는 화면 종료 예시를 안내합니다.
- 일반 주문 5종과 디폴트옵션 옵트인·아웃은 각각 탭으로 확인합니다. 주문 확정은 디자인 확인 창과 정산 시안으로 연결됩니다.
- 퀴즈는 현재 학습카드의 문제·정답·해설을 사용합니다. 오답 벌점 없음, 건너뛰기 전 안내, 점수 상한 상태를 확인할 수 있습니다.
- 수령 방식은 같은 최종 IRP에 대한 두 가지 값을 비교하고 결과 창을 엽니다. 다시 비교할 수 있습니다.

## 상태 예시

상단의 상태 선택은 해당 화면에서 아래 조건을 확인하기 위한 도구입니다. 독립 화면은 기본 상태로 열립니다.

- 06 운용 메뉴: 대기자금 0원 / 리밸런싱 미결제 / 위험비중 70.6% 안내.
- 08 디폴트옵션: 보유 없음의 옵트아웃 비활성, 보유 예시의 환매 입력.
- 10 퀴즈: 점수 상한에서 추가 점수 없이 복습 안내.
- 11 정산: 다음 턴 전 퀴즈 기회 안내.

## 데이터와 규칙의 범위

현재 프로젝트의 UI·엔진을 읽고, 화면의 핵심 문구와 흐름을 기준으로 삼았습니다. 구체적인 참조 파일은 [catalog.json](catalog.json)에 있습니다. 금융 제도에 대한 별도 최신 법령 검수 작업은 이번 디자인 제안에 포함하지 않았습니다.

금액은 [sample.json](sample.json)에 모은 예시입니다. 턴 시작 108,000,000원 → 시장 손익 −1,200,000원 → 추가납입 +1,000,000원 → 정산 후 107,800,000원으로 맞췄습니다. 보유분과 IRP 대기자금의 합계도 같은 평가액입니다. 시장 손익과 외부 입금은 별도 표시합니다.

최종 수령 예시는 별도의 최종 IRP 132,000,000원이며 현재 `accountPayout` 엔진과 가상 원금·이연세액으로 계산합니다. 실제 상품·계좌·세무 계산서가 아닙니다. 거래 입력의 가능액·일정은 화면 상태 예시이며, 실제 적용 시 기존 검증·접수·가격확정·결제 엔진에 연결합니다.

코드 변경은 `docs/design` 안의 디자인 자료에만 있습니다. 운영 게임·저장 데이터·GitHub 배포·Vercel에는 적용하지 않았습니다. 매뉴얼·설정·전체 카드·업적 갤러리는 핵심 화면의 디자인 확정 후 같은 기준으로 확장합니다.
