## 범위

이번 산출물은 HTML/CSS/SVG로 제작한 메인 화면 시안입니다. 기존 `src/ui/avatars.ts`의 캐릭터 벡터를 활용했고, 08에는 같은 코알라를 픽셀 형태로 표현했습니다. 웹폰트·외부 이미지·외부 API 호출 없이 미리볼 수 있습니다. 운영 게임 소스와 저장 정보에는 접근하지 않습니다.

시작/이어하기/설정/자료 버튼은 디자인 시연용 안내창을 엽니다. 새 판 준비의 상세 규칙, 캐릭터·시나리오·주간 도전·기록 등의 최종 배치는 선택한 안을 실제 앱에 연결할 때 정합니다. 현재의 성향 확인 → 디폴트옵션 선택 순서와 추천/선택 구분은 유지할 전제로 설명했습니다. 지도·경로·궤도는 메인 화면의 상징이며 실제 게임 규칙 변경 제안이 아닙니다.

각 안의 ‘움직임’ 설명은 채택 후 발전 방향입니다. 현재 시연에서는 일부 주사위/캐릭터의 느린 부유만 적용했습니다. `prefers-reduced-motion`에서는 멈춥니다. 06의 입체 표현은 SVG의 기하학적 변형과 그림자이며 실시간 3D 렌더링은 아닙니다.

제안서 후보와 의견은 별도 키 `pension-road-design-concepts-2026-09-15`에만 저장합니다. 접근이 차단된 브라우저에서는 메모 파일로 보관할 수 있습니다. 운영 게임의 localStorage 키는 읽거나 수정하지 않습니다.

글꼴은 시스템 고딕·명조를 사용하므로 운영체제별로 자형이 달라질 수 있습니다. 실제 채택 시 라이선스 확인 후 한글 웹폰트를 확정하고 모바일 가독성을 다시 검증하는 것이 좋습니다.

## 재생성

프로젝트 루트에서:

```sh
npx tsx docs/design/2026-09-15-main-concepts/build.ts
```

원본은 `build.ts`, `screens.css`, `viewer.css`, `viewer-script.txt`입니다. 생성되는 HTML에는 스타일과 필요한 데이터·스크립트가 포함되어 있습니다. `index.html` 미리보기 자체는 단독으로 동작하며 ‘독립 화면 열기’ 링크를 사용하려면 같은 폴더의 `concept-*.html`도 필요합니다.
