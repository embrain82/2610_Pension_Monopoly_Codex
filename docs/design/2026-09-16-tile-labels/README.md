2026-09-16 · 디자인 검토용. 게임 코드는 수정하지 않았습니다.

- 원본 요청: 캐릭터가 칸 이름을 가리는 문제. 크기를 조금 줄이고 캐릭터 아래에 이름 배치.
- 기준 코드: `429a288`, 칸 100 × 100 SVG 좌표, 모바일 글자 18 / 데스크톱 16, 기준선 y=70.
- 말 크기: 현재 모바일 너비 80.5칸 단위 및 발 정렬을 기준으로 모든 안 동일. A1 화이트 스티커 표현 유지.
- 공개된 칸에 일관된 이름 배치를 적용하는 안입니다. 미공개 칸의 B5 지도 스티커는 유지합니다.

| 안 | 구성 | 글자 크기 | 기준선 | 의도 |
|---|---|---:|---:|---|
| 01 (추천) | 기본 하단 배치 | 15 | 84 | 기존 톤과 가장 자연스럽게 연결 |

수치는 한 칸 100 기준이며 CSS px가 아닙니다. 전체 보드 표시 너비에 따라 실측 글자 크기가 달라집니다. 05안의 짧은 이름은 기준선 85에 한 줄로 표시합니다.

## 파일

- `index.html`: 기존 캐릭터 PNG 5개를 base64로 내장한 단일 HTML. JavaScript가 켜진 브라우저 필요.
- `comparison.png`: 기본 코리 / 분산 광장 / 현재 배치 + 5안 비교.
- `template.html`, `build.mjs`: 재생성용 소스 (`node docs/design/2026-09-16-tile-labels/build.mjs`).
- `qa-results.json`: 이미지 디코딩·8개 이름/5개 시안의 글자 경계·반응형 검사.

HTML에서 캐릭터·표정·칸 이름·말 위치를 바꾸고, 고른 안을 전체 판에서 확인할 수 있습니다. 선택 내용 복사는 구현 승인과 구분됩니다. 게임의 localStorage를 읽거나 변경하지 않습니다. 주사위·이동·금융·공개 로직은 시안에 포함하지 않으며, 확정 후 원본 게임에 별도 적용합니다.
