# 올원프렌즈 5종 · 게임 캐릭터 디자인 검토

2026-09-15 · 검토용 제안. 게임 코드·투자성향·주문 규칙·저장·운영 배포 변경 없음.

[다섯 캐릭터 비교 페이지](index.html)에서 캐릭터를 전환하고 공식 원형과 비교하며 의견을 남길 수 있다. 상태·메모는 이 페이지 전용 로컬 저장 키에만 저장한다. `채택 검토`는 게임 반영을 실행하지 않는다. 의견은 JSON으로 내려받을 수 있다.

각 시트는 선택창 전신, 게임판 배치, 대기·이동·도착 포즈를 보여준다. 기존 A-1의 흰색·녹색·파스텔과 부드러운 입체 질감을 적용했다. 공식 종족 설정을 바꾸는 안이 아니라 기존 거북이·코알라·여우·사슴·치타 게임말을 올원프렌즈로 바꾸는 외형 제안이다.

## 설계 기준

- 선택창의 인물 크기와 카드 구조를 통일하고 이름·테두리·선택 표시를 함께 사용한다.
- 게임판 말은 얇은 받침 위 작은 전신을 기본으로 한다. 칸 글자 공간을 확보하고 코리는 큰 귀를 포함한 가로 폭으로 크기를 맞춘다.
- 포즈는 대기·짧은 점프 이동·도착 반응을 제안한다. 이미지에 모션 상태를 그린 것이며 실제 애니메이션 파일은 아니다.
- 캐릭터 선택은 투자성향·위험한도·수익률·게임 능력을 바꾸지 않는다. 기존 두 주사위와 이동 방식은 유지한다.
- 시트의 게임판은 크기·배치 비교용 확대 예시다. 24칸 경로, 칸 이름·아이콘·금융 규칙의 변경안은 아니다. 생성 이미지의 부가 문구는 확정 카피가 아니다.
- 채택 후 투명 배경의 개별 포즈 자산, 화면용 크기 조정, 선택창과 실제 24칸 게임판 연결을 구현한다. 이번 원본은 전체 비교 시트 PNG로 직접 게임말에 넣는 파일이 아니다.

## 출처와 생성

[NH농협은행 공식 올원프렌즈 소개](https://www.nhbank.com/goSubPage.do?srchGb=KO_NHPR_17&srchSiteGb=KR)의 캐릭터 이미지 5개를 정체성 참조로 사용했다. `references/*-official.png`는 공식 원형 자료, `assets/*-review.png`는 이를 참고한 새로운 AI 디자인 시안이다. 공식 배포 신규 자산으로 표시하지 않는다.

스타일은 현재 A-1의 `public/assets/design-a1/mascot.jpg`, 게임판 문맥은 D2a의 `board-desktop.png`를 참고했다. 제공 원형과 생성된 5장을 모두 눈으로 비교했다. 올리·원이의 기존 메인 톤에 맞추되, 실제 적용 전 달리의 배 무늬·단지의 귀 비율·코리의 가로 폭은 검토 대상으로 남긴다.

- 생성 도구: Codex 내장 `image_gen` (별도 API CLI 미사용).
- [정확한 프롬프트 5개](image-prompts.json).
- [공식 참조 URL](sources.json), [생성 파일과 원본 경로](manifest.json).
- 생성 원본 PNG 5장을 그대로 프로젝트에 복사했다. 이미지 후처리·게임 반영은 수행하지 않았다.

## 확인

생성 시트 5장의 캐릭터·선택창·게임판·세 포즈를 시각 확인했다. 비교 페이지는 Ego Browser에서 320/390/1440px × 5캐릭터의 이미지 로딩·키보드 전환·단일 선택 상태·가로 넘침을 확인했다. [15회 DOM 검사 기록](qa.json). JavaScript 문법 검사 통과. 실제 게임 애니메이션이나 실기기 사용성 검증을 의미하지 않는다.

[외부 열람용 단일 HTML](allone-characters-standalone.html): 시안 5장과 공식 원형 5장, 스타일·동작을 모두 내장한 약 9MB 파일. 별도 폴더 없이 오프라인에서 10개 이미지가 로딩되며, JavaScript 비활성 상태에서도 시안 5장을 볼 수 있음을 검증했다. [검증 기록](standalone-browser-qa.json).
