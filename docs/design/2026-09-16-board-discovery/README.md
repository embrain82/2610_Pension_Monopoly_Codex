# 게임판 캐릭터 식별성 / 도착 칸 공개 디자인 검토

2026-09-16. 사용자 요청에 따른 디자인 제안이며 운영 게임은 변경하지 않았습니다.

## 전달 파일

`board-design-review-v3.html` 파일 하나만 전달하면 됩니다. 기존 `index.html`도 같은 내용으로 갱신했습니다. 약 6.2 MB이며 원본 캐릭터 PNG 5종과 사용자 캡처 1장을 base64로 포함합니다. CSS, JavaScript, 제안 데이터도 모두 내장되어 있습니다. 외부 폰트나 CDN, 네트워크 요청은 없습니다. JavaScript 실행이 가능한 브라우저에서 열어야 시안과 시연이 작동합니다.

- A1~A5: 화이트 스티커 / 내 말 배지 / 도착 스포트라이트 / 입체 보드게임 말 / 캐릭터 위치 핀
- B1~B5: 뒤집히는 탐험 카드 / 안개 걷히는 길 / 접힌 종이 창 / 오늘의 탐험 봉투 / 탐험 지도 스티커
- 사용자 검토 선택: A1 + B5, 미리보기 원이. 실제 게임 구현 승인 대기입니다.
- 5종 캐릭터 전환, 25개 조합, 주사위 2개와 이동/공개 시연, 선택 내용 복사를 제공합니다.
- 모션은 HTML/CSS 컨셉 시연이며 제품의 최종 물리·양면 애니메이션은 아닙니다.

## 범위 / 구현 원칙

출발 칸만 처음 공개하고 최종 도착한 칸을 자동 공개하는 안입니다. 기존 방문 기록을 표시 계산에 재사용하고, 초기 공개를 실제 방문으로 더하지 않습니다. 기존 저장본은 전체 공개 유지, 새 게임부터 도착 공개를 적용하는 방안을 제안합니다. 주사위·금융·보상·지역 도장 계산은 변경하지 않습니다.

현재 작업 브랜치 `codex/title-focus-outline`의 PR과 이 문서는 별개입니다. 기존 `docs/design/` 전체를 일괄 스테이징하지 않습니다.

## 소스 / 재생성

- `content.json`: 10개 안의 설명, 구현·모션·주의·검증·예상 작업량
- `review.css`, `review.js`: 문서와 시연
- `template.html`: 전체 구현 계획
- `build.py`: 원본 PNG를 편집하지 않고 base64를 삽입. 일반 img 요소와 CSS 표시 창으로 첫 포즈를 표시

프로젝트 루트에서 `python3 docs/design/2026-09-16-board-discovery/build.py`로 생성합니다. 재생성에는 `public/assets/characters/allone/*.png`와 `build.py`에 지정된 사용자 첨부 원본이 필요합니다. 완성한 HTML을 열 때는 이 원본이나 소스 파일이 필요 없습니다.

## 문서 검증

`qa-results.json` 참조. Ego Browser의 로컬 file URL에서 수행했습니다.

- 5개 A안 / 5개 B안 생성 확인, 실제 PNG 5종 2172×724 디코딩 성공
- 25개 조합, 5종 전환, 모든 B안의 최종 도착만 공개 동작 통과
- 미공개 클릭으로 정보 열리지 않음, 동작 줄이기, 이동 중 초기화 통과
- 320/390/430/768/1440px 문서 가로 넘침 없음
- 네트워크 오프라인에서 새로고침·이미지 로드·주사위 시연 성공
- 이미지 6개 base64 검증, 외부 의존성 0개, 정적 ID 중복 없음, JS 구문 검사 통과

제한: `Page.captureScreenshot` 시간 초과로 픽셀 스크린샷 외관 검증은 완료하지 못했습니다. 실제 iPhone 검증과 금융 엔진 회귀 검증은 이 문서의 제품 구현 후 계획에 포함되며 현재 수행한 것으로 주장하지 않습니다.

## 이미지 표시 수정 (v2)

SVG symbol/use 간접 참조를 제거하고 img src에 base64 PNG를 직접 연결했습니다. 기존 파일도 갱신하고 캐시/이전 탭과 구분할 수 있도록 board-design-review-v2.html을 함께 제공합니다. 원본 PNG는 변경하지 않았습니다. 브라우저에서 12개 img의 디코딩과 레이아웃, 5종의 실제 표시 영역 안 픽셀을 확인했습니다. 화면 캡처 API 시간 초과 제약은 계속 남아 있습니다.

## 검토 선택 및 도착 색상 반영 (v3)

`selection.json`에 사용자 검토 선택 A1+B5 · 원이, 공개 규칙, 추가 의견, 실제 게임 구현 승인 대기를 기록했습니다. 현재 칸의 흰 배경 덮어쓰기를 제거하여 공개 순간부터 고유 배경색이 보이도록 시안을 수정했습니다. 말이 떠난 뒤에도 같은 색상을 유지합니다. 원이는 미리보기 선택일 뿐 게임 캐릭터 선택 기능은 유지합니다. 게임 코드·금융·주사위·도장 계산은 변경하지 않았습니다.

검증: `qa-selection-v3.json`에 390px 브라우저에서 A1+B5·원이 초기값, 구현 승인 false, 첫 공개 순간 운용지시 칸 색상, 다음 도착 후 이전 칸 색상 유지, 9종 칸의 현재/비현재 배경 일치, 동작 줄이기 결과를 기록했습니다. 운영 게임이 아닌 배포된 시안을 검증했습니다.
