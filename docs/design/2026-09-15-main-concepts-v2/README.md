## 공통 톤과 캐릭터

흰 배경, 밝은 회색, 녹색 주요 버튼, 파스텔 카드, 고딕 글꼴, 부드러운 입체 그림을 공통으로 사용했습니다. 레이아웃, 보드 크기, 캐릭터 비중, 메뉴 구조를 달리했습니다.

**A — 올리·원이 활용:** [NH농협은행 공식 올원프렌즈 소개](https://www.nhbank.com/goSubPage.do?srchGb=KO_NHPR_17&srchSiteGb=KR)의 녹색 올리와 노란색 원이를 참고해 제작한 AI 디자인 시안입니다. 공식 배포 캐릭터 자산이나 공식 신규 디자인과 구분됩니다.

**B — 기존 캐릭터 재디자인:** 게임의 코알라를 대표로 선택해 회색 몸, 둥근 귀, 검은 코를 유지하고 민트색 포인트와 부드러운 입체 질감을 적용했습니다. 이번 시안은 코알라 중심이며, 채택 후 다른 게임 캐릭터에 같은 기준을 확장할 수 있습니다.

첨부 이미지에서는 생활혜택 카드, 서비스 소개, 퇴직연금 메뉴, 게임 안내의 구성을 참고했습니다. 개인 계좌 화면이나 포인트 잔액 등 첨부 화면의 개인 정보는 제안서에 포함하지 않았습니다.

## 열 가지 구성

| 번호 | 구성 | 핵심 차이 |
| --- | --- | --- |
| 01 | 한 장 소개형 | 짧은 소개와 큰 그림, 넓은 여백 |
| 02 | 파스텔 플레이 홈 | 플레이·방법·학습·기록을 2×2 카드로 배치 |
| 03 | 보드게임 쇼룸 | 큰 보드 카드와 12턴·24칸·내 선택 정보 |
| 04 | 캐릭터 가이드형 | 말풍선과 큰 캐릭터가 맞이하는 화면 |
| 05 | 은퇴 여정형 | 경로 그림과 주사위·시장·운용 선택의 세 단계 |
| 06 | 이어하기 대시보드 | 현재 턴과 진행 상태 중심의 재방문 화면 |
| 07 | 간편 메뉴형 | 작은 보드와 읽기 쉬운 행 단위 메뉴 |
| 08 | 플레이 준비형 | 성향 확인·디폴트옵션 선택·플레이 설정 순서 |
| 09 | 세 장의 소개 카드 | 여행·선택·배움을 직접 전환하는 소개 탭 |
| 10 | 그린 플레이 라운지 | 녹색 캐릭터 배너와 두 개의 파스텔 카드 |

03번은 보드게임임을 가장 명확히 보여주는 기본안, 02번은 기능 탐색을 위한 안, 04번은 캐릭터의 친근함을 강조하는 안으로 추천합니다. 예를 들어 “03-B를 기본으로 02번 메뉴 적용”처럼 구성과 캐릭터를 따로 고를 수 있습니다.

## 시안의 동작 범위

시작·자료·환경설정 버튼은 연결 흐름을 설명하는 창을 엽니다. 실제 게임 실행, 성향 변경, 금융 거래, 게임 저장 데이터 변경은 수행하지 않습니다. 이어하기의 4턴은 시안용 예시입니다. 09번은 여행·선택·배움 탭을 누르거나 방향키로 전환할 수 있습니다.

이 제안은 메인 화면 검토용입니다. 보드 그림의 칸 수와 경로는 표지 일러스트이며 실제 게임판 구현과 일치하도록 제작된 자산은 아닙니다. 채택 후 실제 24칸 게임판, 선택한 캐릭터, 현재 시작 절차에 맞게 최종 자산과 화면 연결을 정리합니다. 기존 게임 코드와 배포에는 변경이 없습니다.

## 생성 자산과 재생성

- 생성 방식: **Codex 내장 Imagegen (`image_gen`)**. 별도 이미지 API 스크립트는 사용하지 않았습니다.
- [정확한 생성 프롬프트 6개](image-prompts.json): A/B 각 보드, 캐릭터, 여정 그림.
- `assets/*-a.png`, `assets/*-b.png`: 생성 원본 6개.
- 같은 이름의 JPEG: 브라우저 시안을 위한 용량 최적화 사본.
- `index.html`은 그림과 화면 정보를 내장한 독립 제안서입니다. 독립 시안 20개는 `assets` 폴더와 함께 보관합니다.

재생성 명령:

```sh
npx tsx docs/design/2026-09-15-main-concepts-v2/build.ts
```
