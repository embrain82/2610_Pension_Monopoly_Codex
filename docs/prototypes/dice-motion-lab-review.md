# 주사위 연출 비교 및 게임 효과 설정

- 비교 파일: `dice-motion-lab.html` (외부 리소스 없는 단일 HTML, 로컬 파일로 열기 가능)
- A: 탁자 위 굴림 / B: 짧게 던져 착지 / C: 부드러운 슬라이드
- 동일한 눈으로 세 안 동시 재생, 개별 재생, 속도 0.6×/1×/2×, 정지·초기화, 결과 표시, 후보 선택 지원.
- 후보 선택은 페이지에만 표시하며 게임 설정·저장·배포에 반영하지 않음.

## 게임 코드 수정

기기 설정 따르기 / 게임 효과 켜기 / 게임 효과 끄기를 추가했다. JS 실행 판단과 CSS 제한이 같은 최종 동작 설정을 사용한다. 켜기는 OS의 reduced-motion보다 우선하고 끄기는 결과를 즉시 표시한다. 이전 reducedMotion 저장값을 보존하며 새 선택값만 추가 저장한다. 운영체제 설정 변경은 기본 모드에 계속 반영된다. 기존 주사위 디자인과 금융 엔진은 그대로이다.

## 검증

- 78개 테스트 파일, 776개 테스트 통과. 타입 검사·린트·프로덕션 빌드 통과.
- OS reduced-motion=true를 모의한 UI 테스트에서 게임 효과 켜기 → CSS 제한 해제 → 주사위 오버레이 → 턴 진행 확인.
- 실제 로컬 브라우저에서 효과 선택 및 새로고침 후 선택 유지 확인.
- 시뮬레이터: 세 안 3+5=8칸, 1+6=7칸 일치; 모의 OS 끔 + 켜기 재생, 시스템 따르기/끄기 즉시 결과, 개별 재생·중단·선택 확인.
- 1440px 및 390px 브라우저 너비 확인; 모바일 가로 넘침 없음. 콘솔 오류·경고 없음.
- 실제 Windows Edge에서의 검증은 아직 하지 않았으며 모의 조건 검증과 구분한다.
- 위 검증은 비교 페이지 제작 시점의 기록이다. 이후 사용자가 B안을 확정했으며 아래 통합 검증을 추가했다.

## B안 확정 및 본 게임 통합

- 짧은 포물선과 두 번의 작은 반동, 착지 그림자, 두 주사위 85ms 시간차를 본 게임에 적용.
- 기본 굴림 1700ms + 마지막 주사위 지연 85ms + 결과 확인 280ms. 2×에서는 전체 시간을 절반으로 줄임.
- 마지막 착지 후 두 눈과 합계를 표시하고 기존 엔진의 이동·시장 반영을 수행.
- 효과 설정 및 저장 호환성 변경을 함께 포함. 금융 엔진·데이터 변경 없음.
- 78개 파일 777개 테스트 통과, 빌드·린트·타입 검사 통과. 기존 번들 크기 경고 유지.
- 로컬 실제 브라우저에서 B안 오버레이, 착지 후 첫 턴 운용까지 검증; 콘솔 오류 없음.
- 실제 Windows Edge에서는 사용자 확인이 필요하며 OS reduced-motion 조건은 자동화 테스트로 모의 검증.

## 원본 B안 일치 수정 / 기본 1.5배속

앞선 통합은 원본 WAAPI를 CSS keyframes로 바꿔 구간별 easing과 회전 보간이 달라졌으며, 크기·원근감·그림자도 변경되어 있었다. 이번에는 원본 HTML의 B 분기를 기준으로 WAAPI 프레임과 옵션을 그대로 적용했다. 62px 주사위, 94px 중심 간격, 각 주사위의 600px 원근감, 타원 착지면, 점과 그림자 스타일을 복원했다. 게임 배경과 결과 안내는 기존 게임 흐름에 맞게 유지한다.

- 원본 HTML과 공개 비교 페이지의 SHA-256 일치 확인.
- 원본 HTML의 B 분기를 직접 실행해 얻은 프레임/옵션과 게임의 계획을 비교: 6개 눈 × 좌우 × 1/1.5/2배속 모두 일치.
- 새 기본 1.5배속: 1700/1.5ms 굴림, 85/1.5ms 지연. 마지막 주사위까지 끝난 뒤 결과 확인과 기존 이동 진행.
- 이전 기본 1배속은 1.5배속으로 전환, 이전 2배속은 유지. 새 선택 UI에서 명시한 1/1.5/2배속은 저장 유지.
- 전체 79개 파일 779개 테스트·빌드·린트 통과. 실제 브라우저에서 1.5배속 주사위 → 이동 → 생활사건 진행 확인. 콘솔 오류 없음.
