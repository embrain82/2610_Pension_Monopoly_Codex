# FB-046~047 제안 및 영향 분석

2026-09-29. 코드 점검에 근거한 제안이며 이번 작업은 게임 코드 변경·제거·배포를 포함하지 않는다.

## 레이아웃 세 가지

- A 다음 행동 우선형(추천): 다음 행동 + 턴/남은 사건 → 자금 두 칸 → 목표 한 줄 → 점수 상세. 첫 턴 4단계 가이드는 펼침. 발견 수는 보드 바로 아래 유지. 기존 하단 고정 행동 버튼은 그대로 유지하며 중복 버튼을 추가하지 않는다.
- B 목표 우선형: 목표 월 환산 45만원 / 50만원 및 90% 바 → 자금 두 칸 → 다음 행동 → 12턴 진행. 보드게임의 목적을 강조하지만 초보자의 다음 행동은 A보다 덜 두드러진다.
- C 압축 요약형: 현재 턴/다음 행동 → 생활자금/주문 가능/목표 달성률 3열 → 상세 펼침에 정확한 목표액·세전/세후 안내·12턴·점수. 화면이 짧지만 숨은 정보 확인에 클릭이 필요하다. 좁은 폭에서는 두 자금만 나란히 놓고 목표는 다음 줄.
- 모든 안에서 기존 글꼴, 0.9rem 안내, 0.8125rem 자금 라벨, 1.12rem 금액 크기를 기준으로 구성. 실제 적용 시 다른 미션(생활 안정·구매력)과 0원/큰 금액/긴 이름/사건·정산 단계/12턴을 추가 검증해야 한다.

## 직접 영향 없는 기능

기념카드는 uiProgress에만 저장한다. GameState·점수 엔진·정식 quizLog·unlockedCards에 보상을 쓰지 않는다. 따라서 제거 자체는 매매·과세·별·학습 점수·주사위·보드 칸 발견에 직접 영향이 없다. 기존 테스트에도 금융 상태 및 점수 불변 검사가 있다.

정식 학습 카드/관련 문제 풀기, 업적/수집 갤러리, 보드 발견 N/24, 지역 정보와는 별도 기능이다. 'journey' 이름의 브랜드 그림, 결과 IRP 잔액 흐름도 같은 기능이 아니므로 삭제 대상으로 묶지 않는다. 기존 문서의 탐험 설명은 출시 시 수정하고 과거 구현 기록은 이력으로 유지한다.

## 권장 범위 및 위험

앨범만 숨기면 기념카드 획득 문구와 작은 탐험이 남아 사용자가 없는 보상을 찾게 된다. 작은 탐험+기념카드+게임/결과 앨범을 함께 제거하되 4장 목표 안내를 짧게 남기는 범위를 추천한다. 부작용은 장별 선택형 복습 8주제가 사라지는 교육적 감소이며, 정식 퀴즈 점수 감소는 아니다.

구현 시 회귀 검증: 기념카드를 0/1/4개 가진 기존 저장판 이어가기, 다른 UI 확인 상태 보존, 기존 점수·자산 동일, 사건 중 저장 복원, 12턴 결과에 앨범 없음, 새 판/분기 연습 정상. 삭제 코드가 아직 없으므로 이번에는 이 제거 후 검사를 실행한 것으로 보고하지 않는다.

## 이번 점검에서 확인한 결과

- 기존 gameplay-simplification 테스트 8개 통과. 탐험이 금융·점수·발견 상태를 바꾸지 않는 현재 구조 확인.
- HTML 시안의 A/B/C 전환, 모바일 폭 전환, C안 상세 펼침을 브라우저에서 확인.
- 게임 코드 변경 없음. 실제 삭제 후 저장 호환성 검증은 구현 단계에서 수행해야 함.
