사용자·운영자 매뉴얼에도 변경된 흐름과 구 버전의 차이를 추가했다. 작은 탐험은 실제 보드 지역 이동과 별개인 선택 학습이다. 장별 안내는 새로운 수익 보너스나 별 조건을 추가하지 않는다.

## 보존한 규칙

성향별 매수 가능 범위, 위험자산 한도, 납입 한도, 생활자금/IRP 구분, 상품별 가격 확정·결제, 만기 통지·대기·자동주문, 예금 약정·중도해지, 중도인출·세금, 최종 정산과 점수 계산을 유지했다. `src/engine`, `src/data`, `src/types.ts`에는 변경이 없다.

통지의 최초 표시만은 기존 UI처럼 상태에 기록한다. 생활사건 등 모달 뒤에 가려진 배경 카드를 통지 표시로 간주하지 않도록 모달 안의 통지만 확인한다. 정산의 만기 카드 중복도 제거했다.

탐험은 `uiProgress.journey`에 저장한다. 현재 장을 넘는 값과 잘못된 값은 버리고 정상 금융 저장은 복원한다. 새 판과 분기 연습은 별도 탐험 진행으로 시작한다.

## Computer Use 실제 플레이

Codex 인앱 브라우저, `http://127.0.0.1:5173/`. 일반 화면과 390×844 모바일 폭에서 조작했다. DOM/키보드/화면으로 진행했으며 브라우저 저장이나 금융 상태를 직접 주입하지 않았다.

시드 **p6yw29-7inhm2**, 안정추구형, 저위험 옵션, 금리의 두 얼굴, 월 50만원 목표.

1. 통합 준비 화면에서 시작. 1장 주문 시간표 탐험에서 오답→정답→기념카드 1/4. 새로고침 뒤 복원 확인.
2. 1턴 100만원 납입. 2턴 장기채 1,001,000원 매수. **2턴 접수→3턴 가격 확정→4턴 결제** 표시와 실제 진행 확인.
3. 3턴 주거 보증금 5,057,383원은 생활자금 사용. 주문 미결제로 막힌 인출 선택의 사유 펼침 확인.
4. 4턴 만기 통지, 5턴 저위험 자동주문. TDF 19,800,302원이 **5턴 접수→6턴 가격 확정→7턴 결제**로 표시. 예금 즉시 처리와 펀드 대기 구분 확인.
5. 5턴 집수리, 6턴 이사 비용을 생활자금에서 해결. 이전 사건과 현재 자금의 연결 안내 및 정산의 생활 선택 표시 확인.
6. 8턴 첫 행동으로 100만원 납입 후 남은 행동 마감. 두 행동이 정산에서 함께 남고 무행동으로 오인하지 않는지 확인.
7. 9턴 200만원 납입, 10턴 보너스 중 200만원 납입. 10턴 목표 500,947원 도달 후 11턴 499,628원으로 하락하여 목표 회복 안내 확인.
8. 12턴 완주, 연금 20년 선택. **3별·84점**, IRP **120,032,932원**, 생활자금 **16,242,356원**, 목표용 세전 월 **500,137원**, 세후 월 **491,356원**. 탐험은 점수에 반영되지 않아 학습 4/20 유지.
9. 결과의 「9턴 끝부터 연습」 실행. 같은 10턴 보너스를 이번에는 전액 생활자금으로 유지하고 12턴까지 재완주. **목표용 월 491,787원·세후 월 483,382원**, 「분기 연습 · 최고 기록 제외」 표시 확인.
10. 결과 첫 카드의 세전 목표/세후 금액 동시 표시, 대표 선택 기록, 성공/미달 판 모두의 3·6·9턴 재도전 버튼 확인. 테스트용 동작 줄이기와 뷰포트 변경은 원복했다.

브라우저 오류·경고 로그는 없었다. 실제 iPhone/Safari 기기와 실제 초보자의 이해도·재미·완주율은 아직 검증하지 않았다. 자동/에뮬레이션 검증으로 사용자의 이해도 향상을 단정하지 않는다.
