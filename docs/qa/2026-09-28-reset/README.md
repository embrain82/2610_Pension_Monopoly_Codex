# 첫 접속 상태 초기화 · FB-028

2026-09-28. 시작 화면 설정 옆 초기화 버튼을 추가했습니다.

## 동작

확인창에서 삭제 범위와 복구 불가를 안내하고, 「기록 삭제하고 처음으로」를 확정하면 이 게임의 두 저장 항목만 삭제하고 페이지를 새로 엽니다. 진행 판·기록·업적·카드·캐릭터·성향·설정이 초기화됩니다. 기본 효과 켜기와 1.5배속, 교육용 동의, 첫 판 캐릭터 선택 흐름으로 돌아갑니다. 다른 앱의 저장 데이터는 삭제하지 않습니다.

초기화 열기·취소·Esc는 저장값을 변경하지 않습니다. 삭제가 실패하면 가능한 범위에서 부분 삭제를 복구하고 오류를 표시하며 새로고침하지 않습니다.

## 검증

- 81개 파일 789개 테스트, 빌드(TypeScript 포함), lint 통과. 기존 500kB 번들 경고 유지.
- 자동 테스트의 독립 저장소에서 초기화 확정→새로고침 호출→기본값 복원→캐릭터 선택 재노출 검증.
- 관련 없는 저장 키 보존, 취소·Esc 보존, 부분 삭제 실패 복구 및 실패 UI 검증.
- 브라우저 390×844에서 설정 옆 배치·확인창 가독성·취소 후 이어하기 유지 확인.
- 브라우저에 남아 있는 기존 플레이 기록은 직접 삭제하지 않았습니다. 확정 후 전체 초기화는 자동 테스트로 검증했습니다.
