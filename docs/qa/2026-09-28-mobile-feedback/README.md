# 모바일 플레이 피드백 FB-023~027 검증

2026-09-28 · 현재 프로젝트 2610_Pension_Monopoly_Codex.

## 구현

- FB-023: 넓은 타원형 바닥판 제거. 개별 주사위 그림자·원본 B안 회전·바운스·기본 1.5배속 유지.
- FB-024: 설정은 켜기/끄기 두 가지. 신규 기본 켜기, 이전 system/기본값은 켜기로 전환. 명시적 off와 이전 reducedMotion=true 선택은 보존.
- FB-025: 저장된 진행과 완료 판이 없는 첫 판 시작 준비 시 캐릭터 선택창 표시. 선택은 준비 초안이며 최종 게임 시작에 저장. 취소 시 이전 선택 유지. 이어서 플레이에는 표시하지 않음.
- FB-026: 용어 도움말은 운용 제목 우측 ? 버튼. 누르면 설명 팝오버를 펼치고 다시 누르거나 Esc로 닫음. 기존 본문 블록 제거. 관련 용어 내용 유지.
- FB-027: 전체 운용 보기는 동일 창에 6개 운용 카드를 펼치고 접음. 쉬운 선택/마감은 그대로 유지, 마감 버튼 중복 없음. 스크롤·키보드 초점·금융 상태 보존. 구 저장 판은 디폴트옵션 카드 없이 기존 5개 운용 카드 제공.

## 자동 검증

- 80개 파일, 784개 테스트 통과.
- 빌드(TypeScript 포함) 및 lint 통과. 기존 500kB 번들 경고 유지.
- 원본 B안 프레임/옵션 일치 검증 유지.
- 신규 mobile-feedback.test.ts: 신규/이전 설정 변환, 첫 캐릭터 선택·취소·이어하기, 펼침의 동일 DOM/스크롤/초점/행동 보존, 도움말 Esc, 바닥판 제거 확인.
- 기존 테스트는 캐릭터 선택 단계 및 명시적 효과 끄기, 변경된 운용 카드 구조에 맞춰 갱신.
- 금융 엔진과 상품 데이터 수정 없음.

## 브라우저 검증

Codex 내장 Chromium 브라우저에서 기존 진행(127.0.0.1) 및 별도 신규 origin(localhost)을 사용. 사용자 저장 데이터 삭제 없이 검증.

- 390×844 뷰포트: 첫 판 캐릭터 선택→올리 선택→시작 준비→성향 확인 확인. 선택 준비 취소 후 설정에는 기존 캐릭터가 유지됨.
- 신규 설정: 게임 효과 켜기/끄기만 표시, 켜기와 1.5× 기본 선택 확인.
- 이어하기→생활사건 해결→운용 창: ? 위치와 용어 표시, Esc는 도움말만 닫고 운용 창 유지.
- 전체 운용: 같은 창에서 쉬운 선택·마감 아래 운용 카드 펼침. 다시 접기 가능. 브라우저 오류 로그 없음.
- 실제 iPhone Safari/Windows Edge 실기기 검증은 수행하지 않음.
