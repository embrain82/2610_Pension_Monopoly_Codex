# Board walking clips

Higgsfield Kling v3.0 Pro image-to-video, generated from the existing neutral mascot artwork.
Five local H.264 clips; no generation API call or credentials are needed by the game.
720x720, about 5 seconds, displayed at 1.5x. Original avatar center/feet framing preserved.
Only the selected character is preloaded. Background removal uses a 256px canvas and edge-connected near-white pixels, retaining enclosed eye highlights.
Playback occurs only during board movement. Reduced motion and media failures retain static art and existing movement fallback.
